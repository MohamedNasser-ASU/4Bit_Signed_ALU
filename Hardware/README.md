# Hardware Notes

This directory contains hardware-related notes for the 4-bit signed ALU project.

## Contents

- `Components_List.md`  
  Lists the main ICs, resistors, capacitors, switches, LEDs, and optional future components used in the project.

- `Pinouts.md`  
  Contains the important pinouts for the logic ICs used in the build, such as adders, gates, and comparator ICs.

- `WiringNotes.md`  
  Contains practical wiring rules, debugging notes, capacitor notes, DIP switch wiring, LED wiring, and module-specific wiring details.

## Purpose

These files are meant to help with the physical breadboard implementation of the ALU.

They document the parts used, how the ICs are connected, and the practical lessons learned while debugging the circuit.
