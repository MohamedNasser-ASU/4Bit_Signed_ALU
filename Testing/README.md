# Testing

This folder contains test case screenshots and photos for the 4-bit signed ALU project.

The tests are divided by where they were performed:

- `Logisim/`  
  Screenshots of test cases from the Logisim simulation.

- `TinkerCAD/`  
  Screenshots of test cases from the TinkerCAD circuit simulation.

- `Breadboard/`  
  Photos of test cases from the physical breadboard implementation.

The purpose of this folder is to show that the ALU modules were tested in simulation and on real hardware.

Test cases may include:

- ADD/SUB results
- Overflow flag behavior
- Comparator outputs
- Multiplier outputs
- Signed two's complement cases

The same important test cases can appear in more than one folder to show that the logic works consistently across simulation and the physical build.
