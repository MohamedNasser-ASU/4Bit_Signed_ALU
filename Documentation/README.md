# Documentation

This folder contains the project documentation files.

## Folders

- `Documents/`  
  Contains the PDF documentation, including the complete project guide, architecture explanation, test cases, component list, wiring notes, implementation notes, and Arduino display system.

- `Block diagrams/`  
  Contains block diagrams that show the ALU structure and how the main modules connect together.

Start with the complete project guide inside `Documents/` for the full explanation of the project.
