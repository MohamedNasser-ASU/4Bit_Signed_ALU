# Documents

This folder contains the main PDF documentation for the 4-bit signed ALU project.

The documents explain the project design, architecture, testing, hardware parts, wiring notes, and Arduino display system.

## Main Guide

Start with:

`complete_project_guide.pdf`

This is the full project guide and gives an overview of how the whole ALU works.

## Other Documents

The remaining PDFs focus on specific parts of the project, such as:

- Project overview
- Architecture explanation
- Truth tables and test cases
- Wiring and diagram guide
- Arduino display system

These files are meant to document the completed ALU project and make it easier to understand, rebuild, or present.
